# Library-Information-System
نظام ويب لإدارة المكتبة تم تطويره بهدف تحويل العمليات الورقية التقليدية إلى نظام رقمي منظم يساعد على إدارة الكتب وسجلات المستخدمين بكفاءة. يوفر النظام قاعدة بيانات مركزية لحفظ معلومات الكتب، مع واجهة سهلة الاستخدام تمكن موظفي المكتبة من إضافة وتعديل وحذف واستعراض بيانات الكتب، مما يقلل الأخطاء ويسهل عملية البحث وإدارة المخزون.
